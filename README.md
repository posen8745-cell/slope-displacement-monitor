# 順向坡雨量警戒模擬

**基隆私立二信高中｜普通科數理班｜P2C29｜張博程**

[開啟模擬網站](https://posen8745-cell.github.io/slope-displacement-monitor/) · [查看原始碼](https://github.com/posen8745-cell/slope-displacement-monitor)

## 為什麼想做這個作品

基隆常下雨，周圍也有不少坡地。我想知道，如果把雨量的變化整理成圖表，再加上提醒，會不會比較容易看出雨勢正在變大？

所以我先從雨量開始，做一個可以操作的模擬網頁。選擇不同降雨情境後，就能看雨量如何累積，以及達到設定值時，畫面會出現什麼提醒。

目前還沒有接上真實儀器，也沒有坡地位移資料。這個作品是在練習呈現雨量變化，不能拿來判斷實際坡地是否安全。

## 我與 AI 的分工

作品的想法、想呈現的情境和功能需求由我提出，網頁程式、圖表及文件由 AI 依照需求完成。我主要負責描述想法、查看畫面，再提出需要調整的地方。程式怎麼處理資料、計算累積量和判斷門檻，是我還需要繼續理解的部分。

## 這個網頁在做什麼

1. **產生模擬雨量：** 可以選一般降雨，或雨勢逐步增強的連續豪雨。
2. **把雨量累加：** 每次更新代表模擬時間經過 10 分鐘，並整理各站的紀錄。
3. **達到門檻就提醒：** 用累積雨量和設定值比較，顯示不同顏色，也可以開啟聲音提示。

我希望看的人可以直接操作，理解「雨量增加 → 累積量上升 → 達到門檻後提醒」這個過程。

## 怎麼操作

1. 選一個模擬站，或按「選雨量最多的站」。
2. 選擇「一般降雨」或「連續豪雨」。
3. 想快點看到變化，可以把更新速度設成「每 10 秒」。
4. 按「開始模擬」，觀察數字、曲線和提醒。
5. 按「停止」可以暫停新增資料；想從頭看，再按「清除紀錄」。

也可以輸入一組經緯度，再按「找最近的模擬站」，試看不同位置會選到哪一站。

## 畫面上的數字怎麼看

| 項目 | 意思 |
| --- | --- |
| 這次 10 分鐘雨量 | 最新一次產生的模擬雨量 |
| 近 24 小時累積 | 模擬時間往前 24 小時內的雨量總和 |
| 近 72 小時累積 | 模擬時間往前 72 小時內的雨量總和 |
| 各站曲線 | 比較各站每次更新的雨量變化 |
| 事件紀錄 | 記下開始、停止、換站及提示變化等操作 |

**更新速度和模擬時間是兩件事。** 例如選每 10 秒更新，實際等 10 秒，畫面就會新增一筆代表「10 分鐘雨量」的資料。

如果目前只模擬了 1 小時，24 小時和 72 小時的累積量可能一樣，因為兩者暫時都只加總了這 1 小時的紀錄。資料還沒累積滿，就不能把它當成完整的 24 或 72 小時雨量。

## 提醒門檻

網頁使用近 24 小時的模擬累積雨量判斷提示，預設值如下，也可以自行修改。

| 提示 | 模擬累積雨量 |
| --- | --- |
| 綠色 | 少於 80 mm |
| 黃色 | 達到 80 mm，還沒到 150 mm |
| 橘色 | 達到 150 mm，還沒到 200 mm |
| 紅色 | 達到 200 mm |

這些數字是展示用的設定，不是官方警戒標準。綠色只表示沒有達到本頁的提醒門檻，並不表示真實坡地安全。

## 資料從哪裡來

目前的三個站都是虛構的模擬站，站名為坡地 A、坡地 B（暴雨測試）和下游 C。站點設定放在 `mock_cwa.json`，雨量則由程式產生，沒有讀取中央氣象署的即時觀測。

選擇連續豪雨時，程式會讓每次更新的雨量逐步增加，再加入一點隨機變化。切換情境會重新計算增強的步數，但原本的歷史紀錄會保留；要從零開始，需先停止，再清除紀錄。

## 檔案與紀錄

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁、按鈕、模擬計算和圖表 |
| `mock_cwa.json` | 虛構站點與降雨情境設定 |
| `README.md` | 作品介紹及操作說明 |

三個檔案放在儲存庫同一層。更新首頁時，檔名要保持 `index.html`，`mock_cwa.json` 也不要改名，才能讀到目前的站點設定。

模擬紀錄會存放在目前使用的瀏覽器，換一台裝置不會自動帶過去。網頁開著並開始模擬後才會新增資料，關閉後不會繼續在背景監測。

## 這次想學習的事

這個作品讓我注意到，除了讓數字和圖表動起來，還需要把資料的意思說清楚。例如，現在看到的是模擬雨量還是真實觀測？累積時間有沒有滿？燈號是根據什麼門檻改變？

我目前先用 AI 把想法做成可以操作的網頁，接下來想慢慢看懂資料讀取、累加和條件判斷的程式。之後如果要加入真正的雨量或位移資料，也需要先了解儀器量測的是什麼，以及資料能用來回答哪些問題。
